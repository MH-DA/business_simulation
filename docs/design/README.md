## 시안과 개발 지침이 다른 곳

개발은 프로젝트 지침을 따르고, 아래는 디자인 담당이 고칠 예정이에요.

- 분석 결과 화면 버튼: 시안은 "대화 시작하기", 지침은 "다음 단계로"(→ 경쟁 가게 비교)
- 회원가입·로그인 입력란은 "아이디"인데 회원가입 오류 문구는 "이미 가입된 이메일"이에요. 로그인 식별자(아이디/이메일)는 팀이 정해야 해요.
- 경쟁사 비교 결과의 "우리 가게의 강점과 약점" 카드: "강점/약점" 판정과 "부족해요·강화할 필요가 있어요" 같은 단정은 서비스 원칙(판정 없이 사실만, 판단은 사장님)과 맞지 않아요. 개발은 같은 자리에 "두 가게의 차이"(코드가 계산한, 각 가게 쪽이 더 많거나 있는 항목)를 보여줘요.
- 경쟁사 URL 입력 화면에 건너뛰기가 없어요. 지침상 건너뛸 수 있어야 해서 개발은 작은 "비교 없이 다음 단계로" 링크를 넣어요.
- 상담 시작 화면의 "마케팅 개선 단계" 설명이 "마케팅 시작 단계"와 같은 문구예요. 개발에서는 개선 단계에 맞는 설명을 사용해요.
